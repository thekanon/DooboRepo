# DooboRepo 디자인 시스템

DooboRepo 디자인 시스템은 공통 UI 컴포넌트를 위한 일관된 디자인 가이드를 제공합니다. 이 문서에서는 디자인 시스템의 핵심 요소를 설명합니다.

## 개요

DooboRepo 디자인 시스템은 Turborepo 기반 모노레포 구조를 활용하여 다양한 프로젝트에서 일관된 사용자 경험을 제공하는 것을 목표로 합니다. 이 디자인 시스템은 다음과 같은 핵심 요소로 구성되어 있습니다:

- **Design Token**: 색상, 타이포그래피, 간격, 그림자 등의 기본 디자인 요소
- **Atoms Component**: 버튼, 입력 필드, 카드 등의 기본 UI 요소
- **Molecules Component**: 원자적 컴포넌트를 조합한 복합 UI 요소
- **Layouts Component**: 페이지 구조를 정의하는 레이아웃 요소

## 컴포넌트 구조

DooboRepo 디자인 시스템은 Atomic Design 원칙을 따르며, 다음과 같은 계층으로 구성됩니다.

### Atoms

- **Text**: Text, Heading, Paragraph
- **Input**: Input, Checkbox, Radio, Select
- **Button**: Button, IconButton
- **Display**: Icon, Avatar, Badge

### Molecules

- **Form Elements**: FormField, InputGroup
- **Navigation**: Breadcrumb, Pagination
- **Feedback**: Alert, Toast, Modal
- **Card**: Card, InfoBox

### Organisms

- **Composite**: DataTable, Form, Sidebar
- **Section**: Header, Footer

### Layouts

- **Basic Layouts**: DashboardLayout, AuthLayout
- **Page Layouts**: DataTableLayout, FormLayout

## 구현 및 사용 방법

### 컴포넌트 임포트

```jsx
import { Button, Input, Card } from '@doo/common-ui';

// 사용 예시
<Button variant="primary" size="md">클릭</Button>
<Input label="사용자명" placeholder="사용자명을 입력하세요" />
<Card title="정보">카드 내용</Card>
```

### 테마 활용

```scss
// SCSS에서 변수 사용
@use "@doo/common-ui/scss/variables";

.custom-element {
  color: variables.$color-primary-500;
  font-size: variables.$font-size-lg;
  margin: variables.$spacing-4;
}
```

## 개발 원칙

1. **일관성(Consistency)**: 모든 컴포넌트가 동일한 디자인 언어를 사용합니다.
2. **재사용성(Reusability)**: 다양하게 재사용할 수 있도록 설계합니다.
3. **접근성(Accessibility)**: 웹 접근성 표준을 준수합니다.
4. **성능(Performance)**: 최적화된 렌더링을 제공합니다.
5. **확장성(Scalability)**: 요구사항 변화에 맞춰 쉽게 확장 가능합니다.
