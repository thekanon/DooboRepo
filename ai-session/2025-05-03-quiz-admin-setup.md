# 퀴즈 백오피스 시스템 구현 계획

## 프로젝트 개요

DooboRepo의 퀴즈 백오피스 시스템(quiz-admin)은 퀴즈 콘텐츠를 효율적으로 관리하고 분석할 수 있는 관리자 도구입니다. 기존에 개발된 UI 컴포넌트 라이브러리를 활용하여 일관된 사용자 경험을 제공합니다.

## 주요 기능 영역

### 1. 인증 및 권한 관리(당장 기능은 구현하지 않고 추후 supabase로 대체 예정)

- 관리자 로그인/로그아웃 시스템
- 역할 기반 액세스 제어(RBAC)
- 세션 관리 및 보안

### 2. 퀴즈 콘텐츠 관리(기본적인 CRUD 기능 및 미디어 자산 관리를 next로 구현)

- 퀴즈 생성, 수정, 삭제
- 문제 및 답변 관리
- 카테고리 및 태그 시스템
- 미디어 자산(이미지, 오디오 등) 관리

### 3. 퀴즈 분석 및 통계(기본적인 mock 데이터로 구현)

- 퀴즈 참여율 대시보드
- 문제별 정답률 분석
- 사용자 행동 패턴 분석
- 데이터 내보내기 기능

### 4. 사용자 관리(기본적인 CRUD 기능 및 권한 관리)

- 사용자 계정 조회 및 관리
- 사용자 그룹 관리
- 활동 로그 및 모니터링
