## 프로젝트 초기 설정

- Turborepo 디자인 시스템 스타터 템플릿을 사용하여 모노레포 프로젝트 생성
- 리포지토리 초기화 및 GitHub 연결
- 패키지 네이밍 컨벤션 변경: `@acme/*`를 `@common-ui/*`로, `@repo/*`를 `@doo/*`로 변경

## 애플리케이션 추가 및 구조 정리

- Next.js 애플리케이션(quiz-admin)을 apps 디렉토리에 추가
- 기존 UI 패키지를 `@common-ui/ui`로 리네이밍하고 관련 설정 정리
- Next.js 버전 업데이트 작업 (15.3.2 버전으로 업그레이드 시도)

## 컴포넌트 개선

- 버튼 컴포넌트의 타입 정의 개선 (`JSX.Element`에서 `React.ReactElement`로 변경)
- 버튼 컴포넌트의 자식 요소 처리 방식 간소화로 가독성 향상
