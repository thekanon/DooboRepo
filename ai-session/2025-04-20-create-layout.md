# 백오피스 UI 요소 분류: 레이아웃과 컴포넌트

## 레이아웃 컴포넌트 작성 시 유의점

### 타입 시스템 활용

- 타입스크립트의 강력한 타입 체크를 활용하여 안정적인 컴포넌트를 구현합니다.
- `types/index.ts`에 재사용 가능한 공통 타입을 정의하고, 컴포넌트별 특수 타입은 해당 컴포넌트 파일 내에 선언합니다.
- Props 인터페이스는 명확하고 자세한 JSDoc 주석을 포함하여 다른 개발자가 쉽게 이해할 수 있도록 합니다.
- 유니온 타입과 제네릭을 활용하여 유연하면서도 타입 안전성이 보장된 컴포넌트를 구현합니다.

### 구조와 동작의 명확한 분리

- 레이아웃 컴포넌트(구조)와 기능 컴포넌트(동작)를 명확히 구분합니다.
- 레이아웃 컴포넌트는 UI 구조와 배치에만 집중하고, 비즈니스 로직은 포함하지 않습니다.
- 상태 관리와 이벤트 핸들링은 컨테이너 컴포넌트나 커스텀 훅으로 분리합니다.
- 레이아웃 컴포넌트는 "어떻게 보여질지"에만 집중하고, "무엇을 할지"는 상위 컴포넌트에서 주입받습니다.

### 모듈화 및 재사용성

- 컴포넌트를 기능과 책임에 따라 작은 단위로 분리하여 개발합니다.
- 공통 로직은 커스텀 훅으로 분리하여 여러 컴포넌트에서 재사용합니다.
- 레이아웃 컴포넌트는 구성 옵션을 통해 유연하게 조정 가능하도록 설계합니다.
- 복잡한 레이아웃은 하위 컴포넌트로 분리하고 composition 패턴을 활용합니다.

### SCSS 모듈 최적화

- SCSS 모듈을 사용하여 스타일 스코프를 컴포넌트로 제한하고 클래스명 충돌을 방지합니다.
- 변수, 믹스인, 함수를 활용하여 일관된 스타일 시스템을 구축합니다.
- 중첩 선택자는 최대 3단계로 제한하여 가독성과 유지보수성을 높입니다.
- CSS Grid와 Flexbox를 적절히 활용하여 레이아웃을 구성합니다.
- 미디어 쿼리는 중앙에서 관리하는 믹스인을 통해 일관되게 적용합니다.

### 반응형 디자인 처리

- `Responsive` 컴포넌트를 사용하여 화면 크기에 따라 다른 UI를 렌더링합니다.
- 뷰포트 크기별로 컴포넌트 레이아웃이 자연스럽게 조정되도록 구현합니다.
- 모바일 퍼스트 접근 방식으로 기본 스타일을 모바일에 맞추고, 미디어 쿼리로 큰 화면을 대응합니다.
- CSS 변수를 활용하여 반응형 수치를 관리하고 일관성을 유지합니다.

### 성능 최적화

- 불필요한 리렌더링을 방지하기 위해 `React.memo`, `useMemo`, `useCallback`을 전략적으로 사용합니다.
- 레이아웃 컴포넌트는 가능한 순수 함수형으로 구현하여 예측 가능성을 높입니다.
- 레이지 로딩을 활용하여 필요한 시점에만 컴포넌트를 로드합니다.
- 페이지 레이아웃에서 중첩된 컴포넌트가 많은 경우, 성능 개선을 위해 React Context를 활용합니다.

### 접근성 고려

- 시맨틱 HTML 요소를 적절히 사용하여 접근성과 SEO를 개선합니다(`<main>`, `<nav>`, `<section>` 등).
- 키보드 네비게이션이 가능하도록 포커스 관리를 구현합니다.
- ARIA 속성을 사용하여 스크린 리더 사용자를 위한 접근성을 향상시킵니다.
- 컬러 콘트라스트를 고려하여 가독성을 높이고, 테마 변경(다크 모드 등)을 지원합니다.

### 테스트 용이성

- 레이아웃 컴포넌트는 테스트하기 쉽도록 단순하고 예측 가능하게 설계합니다.
- 데이터와 로직을 분리하여 순수 UI 컴포넌트로 구현합니다.
- 테스트를 위한 데이터 속성(data-testid)을 추가하여 테스트 가능성을 높입니다.
- 스냅샷 테스트와 함께 사용자 인터랙션 테스트도 구현합니다.

### 레이아웃 계층구조 관리

- 페이지 레이아웃 컴포넌트는 기본 레이아웃 컴포넌트를 확장하여 구현합니다.
- 레이아웃 컴포넌트 간의 의존성은 명확하게 문서화합니다.
- 중첩된 레이아웃의 경우 스타일 충돌이 발생하지 않도록 주의합니다.
- 레이아웃 간 상태 공유가 필요한 경우 Context API를 활용합니다.

### 모노레포 및 디자인 시스템 통합

- 모노레포 구조에서 레이아웃 컴포넌트는 공유 패키지로 관리하여 여러 프로젝트에서 일관되게 사용합니다.
- 디자인 시스템의 토큰(색상, 간격, 타이포그래피 등)을 활용하여 일관된 UI를 구현합니다.
- 스토리북(Storybook)을 통해 레이아웃 컴포넌트를 문서화하고 시각적으로 테스트합니다.
- 디자인 시스템의 버전 관리를 통해 하위 호환성을 유지하며 개선합니다.
- 공유 컴포넌트 라이브러리와 백오피스 앱 간의 의존성을 명확히 관리합니다.

### 서버 컴포넌트와 클라이언트 컴포넌트 분리

- 레이아웃 컴포넌트는 가능한 서버 컴포넌트로 구현하여 SSR 성능을 최적화합니다.
- 클라이언트 상태나 이벤트 핸들러가 필요한 부분만 'use client' 지시어를 사용하여 분리합니다.
- 서버 컴포넌트에서는 useEffect, useState 등 React 훅을 사용할 수 없음을 항상 유의합니다.
- 서버 컴포넌트와 클라이언트 컴포넌트 간의 경계를 명확히 하고 props 전달 구조를 단순화합니다.

### 일관된 사용자 경험

- 모든 페이지 레이아웃 컴포넌트는 공통된 디자인 시스템을 따라야 합니다.
- 에러 상태, 로딩 상태, 빈 상태 등 다양한 상태에 대한 일관된 UI를 제공해야 합니다.
- 토스트, 모달, 드로어 등의 오버레이 요소가 레이아웃을 방해하지 않도록 z-index를 체계적으로 관리합니다.

### 백오피스 특화 기능

- 레이아웃에 권한 기반 렌더링 체계를 통합하여 사용자 권한에 따라 UI 요소를 제어합니다.
- 복잡한 데이터 조작이 필요한 화면에서 사용자의 작업 내역을 추적하고 실행 취소 기능을 제공합니다.
- 장시간 작업 시 세션 유지 및 자동 저장 메커니즘을 레이아웃에 통합합니다.

### 개발 효율성

- 스토리북(Storybook)을 활용하여 레이아웃 컴포넌트의 다양한 상태와 변형을 문서화합니다.
- 레이아웃 컴포넌트의 사용법과 API를 명확하게 문서화하여 팀 내 지식 공유를 촉진합니다.
- 레이아웃 컴포넌트는 비즈니스 로직에 의존하지 않도록 설계하여 재사용성을 높입니다.

## 백오피스 프로젝트 레이아웃 구조 예시

```
packages/common-ui/src/
├── layouts/                 # 레이아웃 컴포넌트
│   ├── base/                # 기본 레이아웃
│   │   ├── DashboardLayout/
│   │   ├── AuthLayout/
│   │   ├── EmptyLayout/
│   │   └── PrintLayout/
│   ├── page/                # 페이지 레이아웃
│   │   ├── DataTableLayout/
│   │   ├── FormLayout/
│   │   ├── DetailPageLayout/
│   │   └── DashboardGridLayout/
│   └── shared/              # 공유 레이아웃 컴포넌트
│       ├── Header/
│       ├── Sidebar/
│       ├── Footer/
│       └── ...
├── ui/              # UI 컴포넌트 (기능)
├── hooks/                   # 커스텀 훅
├── styles/                  # 전역 스타일
│   ├── _variables.scss
│   ├── _mixins.scss
│   └── global.scss
└── pages/                   # 페이지 컴포넌트
```

이러한 구조를 통해 레이아웃(구조)과 기능 컴포넌트(동작)를 명확히 분리하고, 각 레이아웃 컴포넌트의 책임과 역할을 명확히 함으로써 유지보수와 확장이 용이한 백오피스 시스템을 구축할 수 있습니다.

## 레이아웃 (구조적 요소)

### 기본 레이아웃

- **DashboardLayout**: 백오피스의 기본 메인 레이아웃
- **AuthLayout**: 로그인, 가입 등 인증 페이지용 레이아웃
- **EmptyLayout**: 최소한의 스타일링만 적용된 빈 레이아웃

### 페이지 레이아웃

- **DataTableLayout**: 데이터 테이블과 필터, 페이지네이션 등을 포함한 레이아웃
- **FormLayout**: 폼 요소들을 효과적으로 배치하는 레이아웃
- **DetailPageLayout**: 상세 정보 페이지를 위한 레이아웃
- **DashboardGridLayout**: 대시보드 위젯을 그리드로 배치하는 레이아웃
