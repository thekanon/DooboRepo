## 상황 설명

나는 다음과 같은 환경에서 개발하고 있습니다:

- WireGuard VPN을 사용해 원격 서버에 접속
- 원격 서버에 VSCode Remote SSH로 연결
- 원격 서버에서 React/Next.js/Vite 등의 개발 서버 실행 중
- 접속 시도: http://localhost:[PORT]

문제 증상:

- 외부에서 DDNS를 통한 접속 (예: example.domain.com:[PORT])은 정상 작동
- VSCode Remote SSH 세션에서 localhost:[PORT]로 접속 시 문제 발생 (무한 로딩 또는 연결 거부)
- 원격 서버의 IP 주소로 직접 접속 시도 (예: 192.168.x.y:[PORT])해도 연결 거부
