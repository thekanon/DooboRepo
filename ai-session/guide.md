## 개요

모노레포 구조를 활용한 블로그 및 퀴즈 관리 시스템 프로젝트 입니다.

## 프로젝트 소개

DooboRepo는 Turborepo 기반 모노레포 구조를 활용하여 퀴즈 백오피스 시스템과 공통 UI 컴포넌트를 개발하는 프로젝트입니다.
추후 현재 운영중인 https://doombti.vercel.app/ 사이트도 모노레포 구조로 통합할 예정입니다.

## 주요 기능

퀴즈 관리 백오피스 (quiz-admin)
재사용 가능한 UI 컴포넌트 라이브러리
자동화된 CI/CD 파이프라인

## 기술 스택

프레임워크: Next.js 15.3.x
빌드 시스템: Turborepo
패키지 관리: pnpm
스타일링: 미정
CI/CD: GitHub Actions
