### 구조 레이아웃

- **Grid**: 그리드 레이아웃 시스템
- **Split**: 화면을 분할하는 레이아웃
- **Stack**: 요소를 수직으로 쌓는 레이아웃
- **Container**: 너비 제한 컨테이너
- **ScrollArea**: 스크롤 가능한 영역
- **ContentSection**: 페이지 내 콘텐츠 섹션 구분

### 상태 레이아웃

- **LoadingLayout**: 로딩 상태 표시 레이아웃
- **ErrorLayout**: 오류 상태 표시 레이아웃
- **EmptyStateLayout**: 데이터가 없을 때 표시할 레이아웃

## 컴포넌트 (UI 요소)

### 구조적 컴포넌트

- **Sidebar**: 내비게이션 메뉴를 포함한 사이드바
- **Header**: 상단 헤더 바
- **Footer**: 하단 푸터
- **PageContainer**: 제목, 액션 버튼 등을 포함한 페이지 래퍼
- **ModalLayout**: 모달 다이얼로그를 위한 레이아웃

### 내비게이션 컴포넌트

- **MainNav**: 주요 내비게이션 메뉴
- **SubNav**: 서브 내비게이션 메뉴
- **NavItem**: 내비게이션 항목
- **NavGroup**: 내비게이션 그룹
- **TabNavigation**: 탭 기반 내비게이션
- **Breadcrumbs**: 현재 위치를 보여주는 경로 네비게이션

### 콘텐츠 컴포넌트

- **Card**: 콘텐츠를 담는 카드 컴포넌트
- **Panel**: 접을 수 있는 패널 컴포넌트

### 유틸리티 컴포넌트

- **Divider**: 섹션 구분선
- **Spacer**: 간격 조절 컴포넌트
- **Hidden**: 반응형으로 요소를 숨기는 컴포넌트
