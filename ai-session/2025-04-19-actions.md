## CI/CD 파이프라인 구축

- GitHub Actions 워크플로우 설정 추가
- pnpm 설치 및 캐싱 최적화
- 빌드 및 릴리스 프로세스 자동화
- npm 배포 관련 설정에서 트러블슈팅
  - npm 배포가 필요 없음에도 오류가 발생하는 문제 해결
  - 불필요한 npm 인증 단계 제거
- 권한 문제 해결 (`contents: write` 권한 추가)
- GitHub 릴리스 태그 생성 단계 개선
- 브랜치 전략 구현 (feature → develop → release → main)

## 배포 자동화 개선

- changesets 설정 수정 (`ignore` 목록 업데이트)
- 릴리스 브랜치 생성 방식 개선 (외부 액션 대신 git 명령어 사용)
- PR 자동 생성 기능 추가
